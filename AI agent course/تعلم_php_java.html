⚙️ 2. أساسيات PHP — الجملة الأولى

في PHP لا يوجد main ولا تحتاج فئة لتشغيل الكود، الملف يبدأ بـ <?php وينتهي:

$age  = 25;          // عدد صحيح
$pi   = 3.14;       // عائم

🔢 3. الأنواع (Types) في PHP

تشبه Java لكن أسماءها صغيرة وبلا فاصلة منقوطة داخل تعريف:

$a = 10;          // int
$b = 3.14;       // float
$s = "hello";      // string
$flag = false;    // bool
$list = [1,2,3]; // array
$obj = new User(); // object
⚠️ بعد هذا: لا تنسَ نقطة للفصل ;! وكل السطور تنتهي بها، لكن بدون أقواس مفصلة كما في Java.

🔀 4. التحكم في التدفق (If / Loop)

نفس المنطق تمامًا كـ Java، لكن لا حاجة للأقواس المضغوطة في الطباعة — نستبدل System.out.println() بـ echo:

الشرط (if)

if($age >= 18){
    echo "بالغ 🧑";
} elseif($age >= 13){
    echo "مراهق 👦";
} else{
    echo "طفل 👶";
}

الحلقات (for / foreach)

// for — نفس Java
for($i=0; $i<5; $i++){
    echo $i."باك\n";
}

// foreach — مثل enhanced-for في Java
$colors = ["أحمر", "أزرق", "أخضر"];
foreach($colors as $color){
    echo $color.", ";
}
🧪 لاحظ: echo تعرض النص. ودمج النصوص في PHP يكون بالنقطة . وليس علامة +!

🧩 6. الدوال (Functions)

يمكن تعريف دالة في أي مكان، ولا حاجة لـ public static:

function add($a, $b){
    return $a + $b;
}
echo add(5, 3);  // 8

// قيمة افتراضية
function greet($name = "زميل"){
    return "أهلًا " . $name;
}
echo greet();            // أهلًا زميل
echo greet("Mona");    // أهلًا Mona

🏗️ 7. البرمجة كائنية التوجه (OOP)

سيماء مألوفة من Java — class, extends, new, public/private. لكن الفرق الكبير في المصفوفات والجدول:

مقارنة تعريف كلاس

public class User {
    private String name;
    public User(String name) { this.name = name; }
}
class User {
    public $name;          // الاسم

    public function __construct($name){
        $this->name = $name;
    }

    public function getName(){
        return $this->name;
    }
}
✅ لاحظ: بدل this.name نكتب $this->name، وبدل new User(...) نفسها new User(...).

🔀 A. المسارات (Routes)

بدل Servlet / Spring Controller، نعرّف المسارات في routes/web.php:

use App\Http\Controllers\UserController;

Route::get('/users', [UserController::class, 'index']);
Route::post('/users', [UserController::class, 'store']);
Route::get('/user/{id}', [UserController::class, 'show']);

🖥️ B. الكنترولر (Controller)

class UserController extends Controller
{
    public function index() {
        $users = User::all();          // خذ كل المستخدمين
        return view('users.index', ['users' => $users]);
    }
}

🗄️ C. Eloquent ORM (مثل JPA/Hibernate)

الموديل يقابلك بالموديل الخام ولكنه أسهل — الصف هو الطاولة في قاعدة البيانات تلقائيًا:

use Illuminate\Database\Eloquent\Model;

class User extends Model {
    protected $fillable = ['name', 'email'];
}

// الاستعلامات
$user = User::find(1);                 // مثل find
$user->update(['name' => 'Yara']);  // يشبه الملف
User::create(['name' => 'Ali']);   // save مع create
┌──────────────┐ ┌──────────────┐ │ Java (JPA) │ │ Laravel │ │ .find(id) │ → │ .find(id) │ │ .save(obj) │ → │ .save() │ │ @Entity │ → │ Model class │ │ @Table │ → │ $table │ └──────────────┘ └──────────────┘

🛡️ E. الميدلوير (Middleware)

يشتغل مثل Filters في Servlets — يُطبّق عبر المسار:

Route::get('/admin', [AdminController::class, 'index'])
    ->middleware('auth');   // يتطلب تسجيل دخول

📄 F. Migrations — إدارة الجداول

تكتب التغيير في كود، وLaravel ينفّذه على قاعدة البيانات (بدل SQL يدوي):

public function up() {
    Schema::create('users', function (Blueprint $table) {
        $table->id();
        $table->string('name');
        $table->email()->unique();
        $table->timestamps();
    });
}
